# SPXQuery Version 0.4.x Changelog

## v0.4.1 (2026-05-19)

**Git Tag**: v0.4.1

### Refactoring: Unified TAP Query Infrastructure

- **`spxquery.core.query`**: Extracted shared TAP query helpers (`_parse_observation_row`, `_build_band_counts`, `_execute_tap_query`, `_build_adql_band_filter`, `_build_adql_mjd_filter`, `_parse_tap_results`, `_assemble_query_results`) to eliminate ~60 lines of duplicated result-parsing code between `core/query.py` and `batch/query.py`
- **`spxquery.core.query`**: New public function `query_spherex_region()` for circular region queries with `INTERSECTS`/`CONTAINS` coverage modes
- **`spxquery.core.query`**: Unified query execution strategy — sync-first (`service.search()`) with automatic fallback to async TAP job (`submit_job/run/wait`)
- **`spxquery.core.query`**: MJD filtering now applied server-side in ADQL for all query functions
- **`spxquery.batch.query`**: Simplified to thin wrapper delegating to `query_spherex_region()` (148 → 40 lines)

### Performance: Shared Sigma-Clip Implementation

- **`spxquery.processing.background`**: New `fast_sigma_clip()` — pure numpy sigma-clipped statistics replacing `astropy.stats.sigma_clipped_stats()` in both `estimate_window_background()` and `estimate_local_background()`
- **`spxquery.batch.extract`**: Now imports `fast_sigma_clip()` from shared location instead of local duplicate

## v0.4.0 (2026-05-19)

**Git Tag**: v0.4.0

## New Module: `spxquery.drizzle3d`

3D spectral image drizzle pipeline for combining multiple SPHEREx observations into
a single data cube (X, Y, λ) using decoupled spatial + spectral drizzle with
inverse-variance weighting.

### Public API

**src/spxquery/drizzle3d/__init__.py**

- `Drizzle3DConfig`: Validated dataclass for all pipeline parameters with YAML round-trip support
- `drizzle()`: Top-level one-call entry point (query → download → drizzle → save)

### Configuration

**src/spxquery/drizzle3d/config.py**

- `Drizzle3DConfig` with sky region, detector selection, droplet shrink, oversampling, query filters, zodiacal subtraction, and quality cuts
- `to_yaml_file()` / `from_yaml_file()` for reproducible config persistence
- `data_mirror` parameter for local mirror mode (no IRSA download needed)
- Computed properties: `effective_pixscale()`, `output_nx()`, `output_ny()`, `spatial_radius_deg()`, `effective_z_shrink()`

### Grid Construction

**src/spxquery/drizzle3d/grid.py**

- `build_output_wcs()`: 2-D gnomonic (TAN) projection centered on target, 6.15"/pix at `xy_oversample=1.0`

**src/spxquery/drizzle3d/spectral.py**

- `ZGrid` dataclass: bin edges, centers, widths, frequencies, resolving power
- `build_z_grid()`: Three modes — native (17 bins/detector), oversampled (log-spacing), custom user-supplied edges
- Reads SPHEREx spectral channel table from bundled aux FITS file

### Spatial Mapping

**src/spxquery/drizzle3d/spatial.py**

- `compute_spatial_mapping()`: Bilinear weight distribution from input pixels to output grid
- Returns flat arrays for vectorized accumulation (1–4 output contributions per input pixel)

### Drizzle Engine

**src/spxquery/drizzle3d/accumulate.py**

- `DrizzleCube`: In-memory accumulation buffer (flux-weighted, weight, variance, count, AND/OR masks)
- `drizzle_image()`: Per-image accumulation — fully vectorized, no Python pixel loops
  - Group-by unique input pixels via `np.unique`
  - Dense spectral overlap matrix with top-hat kernel
  - Unbuffered `np.add.at` for correct duplicate-index handling

### Pipeline

**src/spxquery/drizzle3d/pipeline.py**

- `drizzle()`: End-to-end orchestrator (build grids → query → per-detector: download → drizzle → save)
- `drizzle_detector()`: Per-detector loop with progress bar
- `_read_input_fits()`: Reads SPHEREx MEF (IMAGE, VARIANCE, FLAGS, ZODI) with optional zodiacal subtraction
- `_extract_wavelength_maps()`: Converts spectral WCS to per-pixel (λ_c, Δλ) maps

### Query & Download

**src/spxquery/drizzle3d/query.py**

- `query_observations()`: IRSA TAP query with `CONTAINS(POINT, poly)` spatial filter, band/MJD/max_images constraints
- `download_observations()`: Sequential download with `skip_existing`, or mirror-mode local path resolution

### FITS I/O

**src/spxquery/drizzle3d/io.py**

- `save_cube()`: 7-HDU FITS output (PRIMARY, SCI, VARIANCE, AND_MASK, OR_MASK, COUNT, WAVELENGTH BinTable)
- `load_cube()`: Reader returning dict of arrays + header
- Approximate 3-D WCS in SCI/VARIANCE for DS9/CARTA compatibility; exact wavelengths in WAVELENGTH extension

### Demo & Tutorial

- `example/drizzle3d_demo/ngc4395_pipeline.ipynb`: Step-by-step tutorial notebook with Colab support
  - Auto-installs dependencies on Colab, downloads pre-computed D3 data from Google Drive
  - Uses mpld3 (Colab) or ipympl (local) for interactive visualization
  - Z-bin slider browser and click-to-spectrum explorer

### Documentation

- `docs/user_guide/drizzle3d.md`: Full user guide with pipeline overview, quick start, configuration reference, algorithm details, output format
- `docs/api/drizzle3d.md`: API reference for all 8 submodules
- `src/spxquery/drizzle3d/README.md`: In-repo module documentation with pipeline diagram
